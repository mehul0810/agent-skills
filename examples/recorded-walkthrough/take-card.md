# Before you press Record

Keep this one card with the raw take, not in a public recording. Use a harmless title or local identifier, not a private URL or customer name.

| Question | Proof desk example | Your take |
| --- | --- | --- |
| What must the viewer see? | The paper changes under the held divider. | |
| What receives the input? | The isolated browser page titled `Proof desk`, 960x600. | |
| What is the recorder capturing? How do you know it matches? | The same Playwright page: the demo sends its input to `page` and finalizes that page's video. | |
| Where do you stop? | On the comparison, before sending anything. | |
| What changes **in the encoded video**? | The boundary between the two papers moves across the page, not just the pointer. | |

If the input and recording refer to different windows, apps or accounts, do not capture. If you cannot identify one yet, mark it missing and hand over the plan instead of claiming the video exists.
