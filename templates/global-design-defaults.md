# Design Defaults

For Pen/Pencil and Figma design work, default to high-fidelity, task-centered composition with clear navigation, credible content and a purposeful visual direction suited to the actual audience and task. Choose a reversible direction from the brief; ask only when an owner decision materially changes scope or outcome. For editable design artifacts (not native macOS app execution), use `references/native-design-authoring.md` inside the installed shared skill (under `$CODEX_HOME/skills/shared`, or `~/.codex/skills/shared` when unset). For standalone generated imagery, use only its **Image Art Direction** section with the installed `imagegen` skill. Preserve exact user targets and keep simple edits proportional. Do not treat a concept image as an editable native design or implementation proof.
