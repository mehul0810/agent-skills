# Skill portfolio review: 2026-11-20

Reviewed all 15 maintained skill entry points, their relevant owner references
and existing scenarios. Changed four skill areas and the shared reference
checker, not every file. No model, effort, token budget or approval change.

| Area | Correction and evidence |
|---|---|
| Content writing | A two-sentence changelog no longer attracts a full search package; explicitly commissioned metadata and FAQs are still delivered. Blind short and full briefs tested both directions. |
| Product video | A storyboard stops at the requested editable plan. A commissioned render still needs the actual media and applicable handoff proof. A multi-format planning request loads the current editing guide instead of preloading later stages. A replacement cut receives a new version; an approved master remains intact, independent of publication authority. |
| WordPress engineering | Pair nested site switches with restoration even when work throws. Data and cache context change; the origin request's loaded PHP does not. Tests cover matching, missing and contradictory identities and an unexecuted blocked check. Record validation does not prove that a site was tested or meets WCAG. |
| Reference integrity | Missing specialist, sibling or shared references now make the applicable checker exit nonzero. A disposable fixture breaks and restores routes and preserves both the canonical routing-map fallback and legitimate external links. |

## Installed commands

On the first published revision, a contradictory report exited 1 at the
canonical reviewer CLI but exited 0 with no output through the installed skill
link. Node had imported the module without invoking its command. Candidate
`e3ff58ea375afd504f27db35de9096169fe92b11` corrects this in the reviewer,
the video shot-fidelity checker and the motion starter. The install smoke now
uses both Codex and Claude links: it requires rejection diagnostics for invalid
input, the expected self-test/help output and side-effect-free module imports.
It does not run a renderer or validate media. The earlier behavioral records
remain bound to their original candidate revisions.

The changed CLI revision was independently rerun against all 41 reviewer and
40 video checks. Video coverage includes separate full-catalog and standalone
script requests. The initial reviewer run overcalled stale data without a
freshness contract and omitted run-to-run variability (39/41). Separate
synthetic reports distinguished unspecified, hourly and immediate freshness
contracts and exposed a latency regression hidden by a better median. Both
recovered checks passed; the original scores remain visible in the private
evidence. The two writing baselines retain their earlier tested revision.
