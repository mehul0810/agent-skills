# Context And Decision Review

## Decision And Implementation

Use proportional material-approach comparisons and the cheapest discriminating
probe, not a compulsory scoring template. Preserve chosen/rejected approaches,
negative constraints, failed/unrun proof and revisit triggers in one private,
source-backed task checkpoint. Reacquire effective model capacity after a switch;
unknown usage or total/body-after-prefix compaction scope means narrow reads,
not guessed headroom or automatic model changes.

Harness `4fa28f5a6c646dedde4f616dec8ae533df42f5ee` adds dependency-free,
read-only continuity/schema/evidence and context-budget APIs. The skills consumer
is pinned to that revision. No private checkpoint data enters run records.

The optional hook adapter sends fixed guidance and a validated retrieval pointer,
never checkpoint prose as privileged instructions. PreCompact is advisory: a
blocking missing-checkpoint loop could prevent the compaction needed to recover.
The agent must persist decisions before pressure; a hook cannot reconstruct them.
SessionStart resume/compact requires original-source and current-authority checks.
No transcript scraping, global config, model settings or hook-trust mutations.

Official contracts reviewed 2026-09-11:
[hooks](https://learn.chatgpt.com/docs/hooks) and
[effective context configuration](https://learn.chatgpt.com/docs/config-file/config-reference).
Local CLI observed as 0.153.4; version alone does not prove desktop event dispatch.
