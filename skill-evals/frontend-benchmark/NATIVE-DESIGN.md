# Native Design Artifact Pilot

Run after decision checks, in an authorized disposable Figma file or Pen workspace.
First prove read/write, fonts, assets, export and save/reopen. Missing access is
blocked; do not install, upload private data, publish libraries or change permissions
to force a pass. Record tool/runtime and vendor-skill versions actually used.

An independent case author freezes one unfamiliar target and truthful content.
Rotate across marketing, dense SaaS operations and mobile task flows; do not require
all surfaces on each run. Supply licensed assets, target/state/width identities and
acceptance criteria. Use the existing blind-packet protocol; keep author criteria
and reference implementation outside the worker packet.

Create a native representative screen and one reused component. Freeze candidate
identity before independent review. Compare renders under matched conditions;
inspect native instances, bindings, editable content and constraints. Through the
editor, resize, change long copy, update reuse, save/reopen and verify propagation
and preserved overrides. Test promised prototype states only; a static deliverable
does not require invented interactions. Preserve originals using a disposable copy.

Record fidelity, craft, native structure, authoring and behavior separately, plus
observed duration, repair cycles and limitations. Unavailable telemetry is not zero.
At most two repair cycles; a failed gate remains failed. Freeze any changed target
as a new attempt, not a repaired baseline. Test imports separately, including lost
interactions and resource dependencies. An export-only pass cannot establish native
editability, and Figma/Pen success cannot pass WordPress's UI-only author gate.

For implementation, continue with `EXECUTION.md` and its existing WordPress proof
schemas. Keep source, design and implementation revisions linked; do not invent a
second production proof schema or claim conversion lift from the pilot. Retain a
sanitized durable result and state raw artifact retention/access explicitly.
