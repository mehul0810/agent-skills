# Handbook Contract Regression Criteria

Author-only scoring. Keep outside evaluator context. These are synthetic decisions,
not a runtime, release, legal-compliance or native-authoring claim.

1. Durable private job record, opaque scheduling ID, visible scheduling failure,
   atomic claim/lease recovery, idempotent side effects and acknowledgement after
   success; no exactly-once guarantee or sensitive scheduler payload.
2. Verify SVN before retry; separate upload, confirmation authorization and public
   ZIP/update API propagation or blocks. Do not confirm without authorization or
   replace a confirmed tag; inspect actual state before further mutation.
3. No blanket production transient purge as a measurement prerequisite. Explain
   cache-condition distortion and use scoped authorized disposable cold-cache work.
4. Email covers guests, verified request flow, page starts at 1, bounded stable-ID
   processing avoids shrinking-offset skips and retained-record loops. Return
   items_removed/items_retained/messages/done. Test empty/exact/multi-batch,
   retained, interrupted and repeated calls.
5. Dynamic rendering does not migrate stored attributes; compatibility reader or
   explicit migration, untouched serialized fixture proof, editor-only migration
   limitations preserved.
6. Editor/entity pending state for editor-owned meta, preserve other edits,
   schema/type/auth/sanitize/REST/custom-fields support, supported save/reload/
   autosave/revision and lower-privilege checks; no universal buffered dispatch claim.
7. Inserted markup persists as post content, source changes do not rewrite old
   pages; bindings/dynamic blocks for live values, editor/save/export verification.
8. Verify current official submission FAQ/guidelines; arbitrary code execution
   including generated PHP and insufficiently differentiated new submissions are
   relevant. Do not invent retroactive closure or a private-product ban.
9. wp_head within head, wp_body_open immediately after body opens, wp_footer
   before body closes; rendered runtime verification rather than source-only claim.
10. Allow scoped authorized disposable fixture invalidation with state documented.
11. Do not impose editor buffering on an intentionally immediate standalone app.
12. Distinguish repeated pattern registration/insertion from existing saved content.
