# Maintainer tickets, November 27, 2026

1. Two plugins receive the same WordPress.org reminder. A: the distributed 2.4.1 ZIP, identified by hash, passed its applicable install/upgrade, role, editor, frontend and integration matrix on 7.1.5 and 7.2-RC3 with Gutenberg off; the other branches have documented non-applicability. B: the development branch activated on one Gutenberg-enabled site; its distributed ZIP and upload integration haven't been exercised. What exact readme change, if any, would you prepare for each? Which version fields stay put, and how should support describe December 8 to customers today? The owner hasn't requested a release.
2. An offload extension's Add New thumbnail works on Firefox. The same photo in a Chromium media picker creates an attachment but the extension misses the small files. It keys off an AJAX flag and hooks only the original upload prefilter. An animated WebP and a quota-limited multisite customer are affected. Which requests, hooks and stored results would distinguish a fix from a successful-looking upload?
3. A block plugin lost its advanced sidebar section and cropper styles. It uses an experimental InspectorControls prop, the old package stylesheet, generated Emotion classes inside a portal and ResponsiveWrapper. Its admin icon CSS targets a Core menu glyph, and a jQuery warning appeared in the same build. Which migrations are necessary, which are not, and what would you exercise across old and new Core?
4. A font and image plugin plans a blanket PHP 8.6 support claim. Its tests combine every historical WordPress test library with the newest PHP. Its TTF allowlist accepts only font/sfnt, a remote stream writes bytes but has no flush method, its GD transform flips with negative dimensions, and hooks record a string from spl_object_hash(). Which combinations and failure paths would you test? Should Core's new support change either advertised minimum?
5. A plugin restores revision meta. An author's autosave of their own draft returned a different shape from a revision. The plugin also filters a comment collection with a scalar comparison and uses an advertised cross-origin method as its access check. A block inserts remote plain text as HTML, uses data-wp-ignore, data-wp-watch--update and data-wp-on--click, and shows a spinner on navigation. Identify incompatible assumptions and what to verify across restore, rendering and navigation.
