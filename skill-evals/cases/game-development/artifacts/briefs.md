# Independent briefs

1. A museum needs a touch game over a fixed overhead view of a fossil drawer. Visitors identify one real specimen and can try again. The museum owns cleared photographs. The oldest kiosk has a web browser, no usable GPU acceleration or network, and a 4 MB content limit. Deliver it in one pass. What would you build?
2. Build a desktop cave-survey game. Walking around a landmark to compare shadow and parallax is the actual survey mechanic. The team has a working native engine project, scanned rocks, collisions and first-person controls. They want a convincing wet/dry boundary when a lamp moves. A producer suggests a slideshow or switching engines for better-looking stills. Pick a direction and the end-to-end first delivery.
3. A new free-orbit exhibit game must launch from a link on managed tablets. The devices can run WebGL 2, but their configured browsers expose no WebGPU adapter. The team knows TypeScript and has glTF objects. An artist suggests using a single photo or making the premium renderer mandatory. What stack and first-device test do you recommend?
4. In a realistic railway-station game, a still looks sharp, but the timber bench and painted metal frame both look like polished plastic. Its feet float. On a moving shot the character's boots slide and footsteps sound the same on gravel and tile. The HUD includes a bright accessibility marker. What would you actually change and re-test?
5. For a 60 fps target, a desktop editor screenshot looks convincing. The handheld build reports a median frame time of 15 ms and p95 of 38 ms on a busy turn after ten minutes. We have not run a full round on that device. Can we mark the game ready? What is the next useful test and tradeoff?
6. Our shipped hand-inked storybook game has an approved art direction. Fix a stuck drag after a pointer cancel. A separate commission wants only a trailer featuring the same characters. Which work, if any, should change art style or engine?
7. A one-shot realistic showroom game is missing a hero car. The only high-detail source available is licensed for a rendered still, not redistributing the model in a game. We also promised interiors for eight vehicles. What can be delivered and what cannot be signed off?
8. Build a one-room fixed-camera watchmaker's puzzle from one request. There are no supplied photos. We have an approved original-image tool and a local renderer. Yesterday's graybox, drawn from circles and gradients, plays correctly but looks like an icon. The player must be able to turn the actual pictured crown. What do you do before calling this pass finished?
