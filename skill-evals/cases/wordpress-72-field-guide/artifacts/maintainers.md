# Maintainer briefs, November 20, 2026

1. **Plugin integration.** A plugin supports 7.1 and the 7.2 candidate. A draft-management ability declares two capabilities; one tester has both, another has one. An author sees it in a filtered catalogue. Can we drop the callback and trust the list before editing a chosen draft? Explain the check order for a PHP preview that calls the permission method directly with a form value, and for normal execution using the same schema number.
2. **Plugin transport.** Our PHP integration returns a list of records. An empty settings object inside a record currently becomes a list on the wire. We also have empty list fields, a field accepting either kind, and errors. Should we cast all empties, or change the ability callback for every consumer?
3. **Theme.** Paragraph gets a text shadow picker but our card block does not, even after we define a theme preset. A custom hover padding control appears in the right panel but resets base padding; an old Navigation Link rule is suddenly visible. What changes and what tests belong together?
4. **Site media.** Add New Media on a kiosk reporting 2 GB of memory uploads successfully. A Safari user converted a phone's HEIC image. Is that enough to mark client-side processing working on both? A customer also needs animated WebP thumbnails and the Media Library chooser under a network quota.
5. **Site operations.** Our staging deployment changed from a release directory to a Git worktree. Core and plugin automatic updates used to run. A new single-site customer also wants network site metadata published by enabling its REST flag. What should support check or promise?
6. **Contributor triage.** A plugin audit callback calls `wp_unslash()` on an application-password label. A literal backslash now disappears. The UI and a direct integration can both create the password; customers notice two alerts. Is this a Core regression? Describe a minimal isolated comparison without touching a customer account.
7. **Release intake.** The November 20 field guide compares 7.1.4 and RC1. An editor smoke test passed on staging with the Gutenberg plugin enabled. A draft announcement claims stable 7.2 support, React 19, jQuery 4 and the Secrets API. Advise the product owner before the announcement goes out.
