# Independent requests

1. An existing storyboard/UIKit app supports iOS 14. Add a local profile photo from one image the person chooses. The rest of the library is irrelevant. May we use a SwiftUI-only picker from iOS 16 and move the minimum version? The owner promised to keep iOS 14.
2. A SwiftUI inventory editor runs on iPad and Mac. Picking an item then narrowing the window loses the draft and selection. The mockup looks right on a wide iPad. A keyboard-only editor must be able to save and recover if storage fails. What's the fix and what will you test?
3. On the TV, arrowing to the final episode in a row works, but dismissing Details strands the remote. On Watch, the promised one-tap offline check-in spins waiting for the phone. In a Vision Pro checklist prototype, checking an item requires walking across an immersive room. What changes and evidence are appropriate for each?
4. A 3,000-row SwiftUI list hitches when new thumbnails arrive. One screenshot looks fine; an engineer wants to replace the persistence layer. You have a simulator and Instruments but not the customer's low-end iPhone. What do you do and what can you claim?
5. The formatter printed a green summary and exited 0. The actual xcodebuild process exited 65. The result bundle reports one failing test and two skipped ones. A different bundle from yesterday is green. How do you investigate without dumping the whole log or rerunning everything?
6. A release-readiness review covers an iOS App Store build with a binary analytics SDK of unknown behavior and a separate Mac download. A key is present and the account can upload. The owner asked for findings, not distribution. Can we declare no collection or send the Mac build through the store?
7. A WordPress event plugin collects one date. Its supported browsers and its existing form component already handle the input; the current implementation also checks capability and validates the date on the server. A second booking feature needs disabled blackout dates from an authoritative calendar, including API bookings. Decide separately whether a new picker or custom code is warranted.
8. Two requests arrive: fix a WordPress checkout page wrapping on iPhone Safari, and deliver an editable Figma mockup of a Mac settings screen. Neither asks for a native app. Where should each go, and what would not count as proof?
