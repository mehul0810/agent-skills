# Engine and session decision scoring

Each brief is independent; grade its decisions and observable proof, not exact prose. Keep this file out of the performer's packet. Routing must match the actual stack or session issue; loading every engine guide is not a pass. These are not player, export, hardware or hosted tests.

| Brief | Decision and proof required |
|---|---|
| Pocket greenhouse | Preserve Unity's project/editor and package pins; recover the original paired metadata/GUIDs without recreating unrelated assets. Treat broken references and a pink low-tier shader as distinct leads; check the active target/Quality pipeline and material compatibility. No unapproved version/HDRP migration. Compare the actual Android player on the affected tier. |
| The clock room | Check the selected Unity 6 Build Profile's effective scene inclusion/order or scripted-build override, not just the open scene/global list. Capture a transient action in its configured input update and consume it exactly once in physics. For the hosted build check the actual compressed resource response, MIME/encoding and loader/build configuration. Verify a cold hosted launch and repeated short taps through a real round. |
| Museum lens | Match core/addons to one installed revision; retain WebGL 2 without requiring WebGPU. Resolve and verify release asset/decoder URLs under the real base path. Derive ray coordinates from the canvas CSS rect, not window or drawing-buffer pixels; keep viewport/projection in sync. In the served game verify selection after scroll/resize, visible focus, keyboard-only and intentional pointer-to-keyboard handoff on the same object, and an exit back to the article without trapping page keys. |
| Workshop replay | One owned render loop/listener lifecycle, release unshared GPU resources only after the final consumer, and compare warmed counters across repeated resets rather than demanding zero. Clear transient input and reset/bound time on return; reproduce the held-key/hidden test without catch-up or duplicate actions. |
| Trail club | On the documented Godot 4 toolchain, ordinary .NET/C# and Forward+ are not a Web export path. Don't promise a toggle, rewrite or streaming. Distinguish a separately approved GDScript/WebAssembly/WebGL 2 Compatibility slice; select an eligible single-thread preset on a supporting minor if the host cannot isolate, and reject required threaded dependencies. Use matching templates and exercise the actual embedded export, not headless native. |
| Station lift | Check project main scene versus running the current editor scene, named preset/templates and exported resource filtering/case. Keep saves in writable player storage, allow the pause control to process while paused, and test entry, lift, pause/resume and persisted progress on a clean offline exported launch. |
| Long weekend | No auto-wipe. Validate a versioned payload, migrate known old saves without destroying the last good copy, preserve invalid/future saves. Wait for transaction completion, distinguish abort/error; test retained progress after relaunch, including failure paths, on disposable slots. |
| One ticket | A single authority accepts the claim once, duplicate/replayed actions cannot double-grant, reconnect reconciles pending intent to an authoritative result, and local pause doesn't freeze shared time. Test a simultaneous claim plus reconnect/replay with two independent clients on existing local resources; a one-process simulation is not sufficient evidence. |
