# Navigation Study Selection: Scorer Only

- **two-explanations:** Gives a concrete task in ordinary visitor language that does not reveal the label, control or route. Keeps the expected destination in the scorer's key. Uses plausible alternate branches in a text tree to test wording/grouping, then a rendered first-choice test with the same task and labels to isolate visual prominence, including narrow navigation. Gives different next decisions for tree failure and rendered-only failure. Distinguishes both from completing the real task.
- **one-correct-click:** Limits the claim to one engineer's desktop first selection. Does not claim customer success, mobile performance or form completion; proposes following and verifying the intended form outcome under safe conditions, keeping audience evidence separate.
- **bounded-label:** Makes only the named copy change; preserves the destination and appearance. No research program, recruitment, tracking, taxonomy migration or redesign.
